# Wedding Artifacts V2

Original deterministic SVG kit for the existing Chinese historical-style wedding site. Preview: open index.html. All source media remains unchanged. No production index/style/script is modified. Rebuild: node tools/build-wedding-artifacts.cjs. SVGs are editable vector sources and deploy-ready for relative-path GitHub Pages. The preview is responsive; integration into the live invitation is intentionally separate. Source date is copied, not verified. Text rendering depends on CJK fonts. No new real couple photography or replacement music is fabricated.
